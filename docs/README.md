# L.R.O. Website Branch
## About
This branch contains the web assets for [yashalego.github.io/licericresearchorganization](https://yashalego.github.io/licericresearchorganization)
## HTML & Pages
### HTML
HTML files are located under `/(root)`
### Pages
Each HTML file in the root folder is a new page, excluding `index.html`, which is the homepage.<br>
A page can be accessed by appending `/pagename` to the URL, where _pagename_ is the name of the page.
## CSS
CSS files are located under `/styles`.<br>
The main CSS file is `main.css`.
## Assets
Any miscellaneous assets are located under `/assets` (media, fonts, etc.).<br>
### Media
Media assets (excluding favicon) are located under `/assets/media`.
### Fonts
Fonts are located under `/assets/fonts`
### Other
The favicon is `favicon.ico` (sizes: 16x16, 32x32, 48x48), and `favicon.png`.
