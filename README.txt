This is the website branch of this reposistory.

  -pages-
Site pages are "pagename.html", where "pagename" is the name of the page.
"index.html" is the homepage.
  -css-
Any CSS files are located in "/styles".
The default CSS file is "/styles/default.css"
  -assets-
The "/assets" folder contains any assets for the website. The favicon is "/assets/favicon.ico" (sizes: 16x16, 32x32, 48x48).
The "/assets/fonts" folder contains any fonts the website uses. The default font is "/assets/fonts/default.otf".
